# coolanas

A small personal site. I've split the bits into folders so it's easier to find stuff.

## Where things live

- `pages/home/` is the landing page
- `pages/workspace/` has the dashboard, activity, analytics, collections and settings pages
- `pages/account/` has the PIN page
- `css/` has the styles (one file for each page)
- `js/` has the scripts
- `assets/branding/` has the logos
- `assets/icons/` has the little browser tab icon

The small HTML files in the root are just redirects for old links. They keep addresses like `dashboard.html` working.

GitHub Pages still needs the root `index.html` and `CNAME`, so those stay there.
